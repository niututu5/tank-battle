# 🎮 坦克大战 (Tank Battle)

一个用纯 HTML5 Canvas 开发的经典坦克大战游戏，无需任何依赖，直接在浏览器中运行。

## 🚀 快速开始

1. 克隆仓库：
   ```bash
   git clone https://github.com/jxcchen/tank-battle.git
   ```

2. 直接用浏览器打开 `index.html` 即可开始游戏！

## 🎯 游戏玩法

- 控制你的坦克，消灭所有敌方坦克
- **保护你的基地**（屏幕下方中央的鹰标志），基地被摧毁则游戏失败
- 每关消灭所有敌人后自动进入下一关
- 共 10 关，难度逐渐递增

## 🕹️ 操作方式

| 按键 | 功能 |
|------|------|
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 移动坦克 |
| `空格` | 发射子弹 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

## 🏗️ 地图元素

- 🧱 **砖墙**（棕色）：可被子弹摧毁
- 🛡️ **钢铁墙**（灰色）：无法被摧毁
- 💧 **水域**（蓝色）：玩家坦克无法通过
- 🦅 **基地**（金色鹰标志）：保护目标

## ✨ 特性

- 纯原生 HTML/CSS/JavaScript，零依赖
- Canvas 渲染，流畅 60fps
- 敌方 AI 自动寻路和射击
- 粒子爆炸特效
- 关卡进度系统（10关）
- 生命值系统
- 无敌保护（受伤后短暂无敌）
- 响应式设计
